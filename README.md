# Redux Toolkit Counter

A small responsive React counter powered by Redux Toolkit. It demonstrates a focused slice, shared store, increment and decrement actions, plus a reset control.

## Features

- Redux Toolkit state management
- Increment, decrement and reset actions
- Accessible buttons and live counter output
- Fixed branded header, responsive card and icon-only footer links

## Tech Stack

React, Redux Toolkit, React Redux, Create React App, Sass and CSS Modules.

## Run locally

```bash
npm install
npm start
```

## Build and deploy

```bash
npm test -- --watchAll=false
npm run build
npm run deploy
```
